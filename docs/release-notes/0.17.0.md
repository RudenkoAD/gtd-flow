# 0.17.0 — выбираемый размер шрифта календаря

Новая настройка **«Размер шрифта календаря»** (Настройки → Календарь):
пресеты Мелкий / Стандартный / Крупный / Очень крупный. Масштабируется весь
вид — сетка месяца, недельный и дневной тайм-грид, агенда, чипы событий и
тулбар — с сохранением внутренней иерархии размеров; «Стандартный» выглядит
ровно как раньше. Работает и в календаре на Android.

Совместимость: минимальная версия Obsidian — 1.11.4 (как в 0.15.0/0.16.0);
формат настроек не менялся.
