# GTD Flow project wiki

This versioned directory is the operational memory for the repository. It
must not contain credentials, OAuth tokens, API keys, private task text, or vault
content.

## Index

- `release.md` — release procedure and current release risks.

Update these notes when a decision, invariant, recovery procedure, or surprising
failure would save time in a future session.
