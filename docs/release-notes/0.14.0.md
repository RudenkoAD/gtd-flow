Android support for the core GTD workflow is now available in Obsidian Mobile.

- Inbox, day calendar, task details editing, and recurring tasks run on Android.
- Desktop-only AI, OAuth, sync, drag-and-drop, and desktop views are isolated from the mobile startup path.
- Widget navigation can open the matching Inbox, calendar date, or task editor through Obsidian deep links.
- Recurring task ownership and generated task IDs converge deterministically across devices.

The AI Inbox remains a desktop-only feature in this release. Update the separate GTD Flow Widgets Android app to `0.5.0` for the matching scope and estimate schema.
